# WinPilot

Take Control of Windows

WinPilot is a modern Windows management suite that combines system monitoring, diagnostics, maintenance, security, privacy, recovery, developer tools, and AI-assisted diagnostics into a single desktop experience.

## Tech Stack

- Electron
- React
- TypeScript
- Vite
- Tailwind CSS
- Shadcn UI
- Zustand

## Features

- System Dashboard
- Security Center
- Privacy Center
- Task Manager Plus
- Startup Manager
- Services Manager
- Recovery Center
- Developer Center
- AI & Diagnostics

## Languages

- Arabic (RTL)
- English (LTR)
